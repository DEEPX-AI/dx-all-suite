DEEPX on AWS Marketplace

DEEPX Compiler Solution

EC2 · S3

DEEPX Compiler Solution runs dxcom on an EC2 instance. Deployed as a CloudFormation stack, uploading an .onnx and its .json to the model bucket compiles a .dxnn next to them.

Open Marketplace listing AWS Console guide

DEEPX Greengrass Solution

IoT Core · Greengrass

DEEPX Greengrass Solution deploys the NPU driver, firmware, dx_rt and dx_stream to every device in a Thing Group, with the compile pipeline in the same stack.

    AWS CLI setup guide

    Studio reads the AWS CLI configuration (~/.aws) on the machine running Studio. It never asks for access keys.

    1. Install AWS CLI v2

      If unzip or curl is missing, install them first:

      sudo apt install -y unzip curl

      One script for Linux x86_64 and aarch64; it picks the package for this machine:

      ARCH="$(uname -m)"   # x86_64 or aarch64
case "$ARCH" in
  x86_64|aarch64)
    curl "https://awscli.amazonaws.com/awscli-exe-linux-${ARCH}.zip" -o awscliv2.zip
    unzip -q awscliv2.zip
    sudo ./aws/install --update
    aws --version ;;
  *) echo "AWS CLI v2 for Linux supports x86_64 and aarch64 only (this machine: $ARCH)" ;;
esac
      AWS CLI install guide

    2. Configure credentials

      Option A: access key Create one in the IAM console (Users, Security credentials, Create access key), then enter it when prompted:

      aws configure
      AWS Access Key ID [None]: AKIA****************
AWS Secret Access Key [None]: ****************************************
Default region name [None]: ap-northeast-2
Default output format [None]: json

      Option B: IAM Identity Center (SSO) Create a named profile once, then sign in when the session expires:

      aws configure sso
      aws sso login --profile <name>
      AWS CLI configuration guide

    3. Verify

      aws sts get-caller-identity

    4. Required permissions

      • CloudFormation
      • S3
      • Step Functions
      • SSM GetParameter
      • EC2
      • IAM (CAPABILITY_IAM)
      • CloudWatch Logs
      • Lambda
      • Greengrass V2 · IoT (Greengrass tab)

      An account admin accepts the Marketplace subscription.

    5. Check the connection

      Click Check connection. New named profiles appear in the profile list; no restart is needed.
