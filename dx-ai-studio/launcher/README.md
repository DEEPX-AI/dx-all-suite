# Launcher — DX AI Studio Hub

The home screen of DX AI Studio and the single entry point you open in the browser. It
starts every module for you and lets you jump into any of them from one place.

## Using it

1. Launch the studio (`./launcher.sh`) and open the shown address in your browser.
2. Wait for the boot screen — it starts all modules and clears when they are ready.
3. Describe what you want in the prompt box and click **Build it** (it opens the right
   module, or runs the coding agent in place), or click a tool card to open it:
   **DX App**, **DX Stream**, **DX Model Zoo**, **DX Compiler**, **DX EdgeGuide**,
   **DX Benchmark**, **DX Monitor**, **DX Agent Dev**, **DX Cloud**.
4. Also on the hub:
   - **SDK Library** — browse the DEEPX SDK documentation and brochures in-app.
   - **About DEEPX** — company, product, and news information.
   - Top bar — **Buy** (DEEPX store), **language** (6), **theme**, **Connected browsers**
     (when other computers can reach the studio) and **Tutorial**.
   - The **DX-M1 widget** and **Measured on DX-M1** card — this board's NPU and measured FPS.

## Key features

- **One-click access** to all nine modules from a single hub.
- **SDK Library** — curated DEEPX docs/PDFs viewable without leaving the studio.
- **About DEEPX** — product and news overview.
- **Purchase entry point** — the **Buy** button in the top bar links to the DEEPX store.
- **Remote access** — other computers pair once with a code shown in the launcher terminal;
  **Connected browsers** lists and disconnects them.
- **6-language UI** (English / 한국어 / 日本語 / 简体中文 / 繁體中文 / Español).
